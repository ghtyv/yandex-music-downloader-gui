Yandex Music Downloader GUI
Version: @VERSION@
Windows x64 Portable

============================================================

Yandex Music Downloader GUI — графическое приложение для
загрузки музыки из Яндекс Музыки.

УСТАНОВКА

Установка не требуется.

1. Распакуйте архив в любую папку.
2. Запустите YandexMusicDownloader.exe.

Python и FFmpeg отдельно устанавливать не требуется.

ИСПОЛЬЗОВАНИЕ

1. Нажмите «Получить токен» и выполните авторизацию Яндекс.
2. Вставьте ссылку на трек, альбом или плейлист.
3. Выберите папку для сохранения.
4. Выберите качество.
5. При необходимости измените дополнительные параметры
   через кнопку «Настройки».
6. Нажмите «Скачать».

Приложение поддерживает:

- загрузку в лучшем доступном качестве;
- FLAC с автоматическим fallback на MP3, когда lossless
  недоступен;
- встраивание обложек;
- настройку разрешения обложки;
- пользовательский шаблон имени/пути;
- пропуск уже скачанных файлов;
- безопасную остановку загрузки;
- повторную авторизацию при недействительном OAuth-токене.

АВТОРИЗАЦИЯ

OAuth-токен получается через встроенное окно авторизации и
сохраняется средствами системного хранилища учётных данных.

Не передавайте свой OAuth-токен другим людям.

ЛОГИ

Технический debug-лог приложения хранится в каталоге локальных
данных приложения Windows.

СТОРОННИЕ КОМПОНЕНТЫ

Приложение использует сторонние open-source компоненты, включая:

- llistochek/yandex-music-downloader
- FFmpeg
- Qt / PySide6

Дополнительная информация находится в файлах
THIRD_PARTY_NOTICES.txt и THIRD_PARTY_LICENSES.txt
